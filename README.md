# car-hunter-data

Public mirror of one file: `listings.json`, the current match set from a private
[car-hunter](https://github.com/AgingMeeseeks/car-hunter) scan.

It exists so a LAN-only display can pull fresh data without holding a GitHub
credential. Nothing here is secret — every record is a public classified ad that
was already on Cars.com, CarGurus, eBay, Cars & Bids or Bring a Trailer.

Rewritten by GitHub Actions after each scan (every 6h). Do not edit by hand.
